# Deas Finance

Versão corrigida em arquivo único.

## Como publicar no GitHub Pages

1. Abra o repositório `Deas` no GitHub.
2. Apague/substitua os arquivos antigos.
3. Envie o `index.html` desta pasta para a raiz do repositório.
4. Faça commit.
5. Abra `https://19041507.github.io/Deas/` e pressione `CTRL + SHIFT + R`.

## Firebase

O app já está com a configuração do projeto `deas-finance` dentro do `index.html`.

No Firebase, deixe ativado:
- Authentication > Método de login > E-mail/senha
- Firestore Database

Cole as regras do arquivo `REGRAS_FIREBASE.txt` em Firestore > Regras > Publicar.
